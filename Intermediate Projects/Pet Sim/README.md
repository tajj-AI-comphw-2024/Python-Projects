# Virtual Pet Simulator

This project is a simple simulation of a virtual pet. Users can interact with the pet by feeding it, playing with it, or making it rest. The pet's stats (health, hunger, and happiness) change based on these interactions.

## Project Details
- **Created**: April 5th, 2025
- **Finished**: May 2nd, 2025

## Skills Developed
- Object-Oriented Programming (OOP)
- Classes and Inheritance
- Attributes and Methods
- Function Design
- User Input Handling

## How to Run
1. Clone the repository or download the project files.
2. Navigate to the project directory.
3. Run the `main.py` file using Python 3.x.

```bash
python main.py
```

## Features
- Choose from different pet types: Dog, Cat, Bird, or Fish.
- Interact with your pet by feeding it, playing with it, or checking its health.
- Randomly generate pet attributes like health, hunger, and happiness.
- Select a breed for your pet or let the program choose one randomly.

## Future Enhancements
- Add more interaction options (e.g., resting, training).
- Introduce a mini-game to improve the pet's happiness.
- Save and load pet data for continued gameplay.

## Libraries Used
- None (pure Python).

## File Structure
- `virtual_pet.py`: Contains the `VirtualPet` class and its subclasses (Dog, Cat, Bird, Fish).
- `pet_actions.py`: Provides functions to interact with the pet (e.g., feed, play, check health).
- `create_pet.py`: Handles pet creation and breed selection.
- `main.py`: The main entry point for the game.
